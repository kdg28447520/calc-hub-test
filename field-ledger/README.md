남부사무소 현장 44곳(원본 대장 42곳 + 판교G2·안산 AS센터) · 품목 1,435건(자재 1,297 / 공도구 138)을 실시간 팀 공유로 보는 대장입니다.

## v2.2.1에서 달라진 점
- **이름 변경**: 화면·제목·매니페스트·허브 문서 이름을 모두 `남부사무소 현장별 자재 및 공도구 대장`으로 통일. (`<title>`, `og:title`, description, 설정 하단, 매니페스트 `name`·`short_name`, Firestore `hubs/FL-G5JRK9.name`)
- **기본 주소만으로 바로 열림**: `https://kdg28447520.github.io/calc-hub-test/field-ledger/` 로 접속하면 그룹 코드 입력 없이 남부사무소 허브(`FL-G5JRK9`)에 자동 연결됩니다. 우선순위는 `?hub=코드` → 이 기기에 저장된 코드 → 기본 허브.
- 서비스 워커 캐시 `field-ledger-v2.2.1`로 갱신 — 이전 캐시로 옛 화면이 남지 않습니다.

## v2.2 구조
- **홈 = 전체 현장**: 앱을 열면 `전체 현장` 뷰가 첫 화면. 하단 탭도 `전체 현장 → 현장 자재 → 사진 찾기 → 이력 → 설정` 순서.
- **1차 분류 `전체 / 자재 / 공도구`**: 전체 현장·현장 자재 두 화면 상단에 분류 칩. 건수 배지 실시간 표시.
  - `자재` = 공종이 공도구가 아닌 건축 마감자재(도배·타일·설비·마루·전기·하드웨어·기타 자재) 1,297건
  - `공도구` = 공종 `공도구` 138건
  - `자재` 선택 시 공종 필터에 마감자재 공종만, `공도구` 선택 시 공도구만 나옵니다.
- **나눔(전출 요청) 기능 제거**: `전출가능` 수량은 ERP 재고 속성으로 배지·필터에 그대로 남습니다.
- **기록 담당자 이름 기본값 비움**: 설정의 이름이 비어 있으면 이력에 이름 없이 기록됩니다.
- **현장별 번들 저장**: `site_bundles/{현장ID}` 문서 1개에 현장 품목 전체. 앱 1회 오픈 = 허브 문서 1 + 현장 번들 44 = **읽기 45건**, 수정 1회 = 그 현장 번들 1건 쓰기.
- **스키마**: 현장코드·품목코드(F000xxxx)·공종·업체·사업자번호(마스킹)·시공부위/위치/단지구분·규격·단위·**전출가능수량**·재고(합계·현장·보관증 + 금액)·사용/입고/인수인계·재고소진예상일·비고
- **필터**: 현장 선택, 1차 분류(전체·자재·공도구), 공종 칩, **전출가능만** 토글, 품목명·규격·품목코드·시공부위·업체 실시간 검색
- **2줄 복합 헤더 TSV/CSV 파서 내장**: 엑셀에서 복사한 원본 그대로 붙여넣기 또는 파일 업로드

## 저장 구조 (Firestore `field-ledger-as`)
| 문서 | 내용 | 읽기 |
|---|---|---|
| `hubs/FL-G5JRK9` | 허브 정보 + `sites`(현장 목록 44) | 1 |
| `hubs/FL-G5JRK9/site_bundles/{현장ID}` | 현장 품목 배열 + 최근 이력 60건 | 44 |
| `hubs/FL-G5JRK9/photos/{id}` | 품목 사진(필요할 때만 1건) | 0~ |

## 사용
1. 기본 주소를 열면 남부사무소 허브로 자동 연결 → 44개 현장 즉시 로드 (로그인 없음, 익명 인증)
2. 첫 화면 **전체 현장**: 44곳 1,435건을 한 화면에서 검색·분류·공종·현장·전출가능 필터
3. **현장 자재** 탭: 상단 현장명을 눌러 현장 전환 → 그 현장 품목·공종·전출가능 확인, + 버튼으로 등록
4. 설정 → **TSV·엑셀 붙여넣기 / 업로드**로 새 대장 반영(같은 품목코드·규격·시공부위·업체는 자동 갱신)
5. 다른 그룹으로 볼 때는 `?hub=FL-XXXXXX` 또는 설정의 [다른 그룹 코드로 입장]

## 무료 한도
Spark 플랜: 읽기 5만/일 · 쓰기 2만/일. 앱 오픈 1회 ≈ 45 reads, 수정 1회 ≈ 1~3 writes → 하루 수백 회 사용해도 한도의 1% 수준.

## 보안
- 프론트에는 Firebase 공개용 Web config만 포함. 원천 대장/사업자번호는 HTML에 하드코딩하지 않고 Firestore에만 저장(사업자번호는 `123-45-*****`로 마스킹)
- v2.2.1부터 **기본 허브 코드가 페이지 안에 들어 있어, 이 URL을 아는 사람은 코드 입력 없이 남부사무소 대장 전체를 열람**할 수 있습니다. 링크는 사내 관계자에게만 공유하고, 외부 공개가 걱정되면 Firestore 보안 규칙에 접근 제한을 추가해야 합니다.
