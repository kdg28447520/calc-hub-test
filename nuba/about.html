서비스 소개

출발 전 3초, 세 내비의 답을 한 화면에서

누빠(누가빠름)는 운전자가 차에 오르기 전에 “오늘은 어느 내비가 더 빨리 도착한다고 말하는가”를 확인하는 웹앱입니다. 티맵, 카카오내비, 네이버지도에 같은 좌표를 동시에 물어 소요시간과 거리, 통행료를 나란히 보여주고, 고른 내비 앱으로 바로 넘겨 줍니다.

최종 수정 2026년 11월 20일

왜 만들었나

같은 길을 가는데도 내비마다 도착 시간이 다릅니다. 그 차이가 3분이면 아무 생각 없이 지나가지만, 10분, 15분이 벌어지면 이야기가 달라집니다. 그런데 세 앱을 번갈아 열어 같은 목적지를 세 번 입력하고 숫자를 눈으로 비교하는 일은 번거롭고, 운전석에서 하기에는 위험합니다.

그래서 출발 전 한 번, 버튼 하나로 세 곳의 답을 동시에 받아 보는 도구를 만들었습니다. 앱을 새로 배우지 않아도 되고, 실제 길안내는 이미 익숙한 각 내비 앱이 그대로 맡습니다. 누빠는 ‘어느 앱을 켤지’를 정하는 3초만 책임집니다.

어떻게 동작하나

  • 좌표를 확정합니다출발지와 도착지를 입력하면 실시간 장소 검색으로 실제 좌표를 확정합니다. GPS 버튼을 쓰면 현재 위치를 한 번 읽어 도로명 주소로 바꿔 출발지로 넣습니다.
  • 세 서비스에 동시에 묻습니다브라우저는 누빠의 서버 함수에 좌표만 보냅니다. 서버가 티맵(SK TMAP), 카카오모빌리티, 네이버 클라우드 플랫폼 Directions 5에 각각 요청을 보내고, 돌아온 응답을 브라우저로 전달합니다.
  • 한 화면에 세웁니다소요시간이 짧은 순서로 카드를 정렬하고, 지도에는 세 회사의 경로를 각자의 브랜드 색으로 겹쳐 그립니다. 카드를 고르면 그 노선이 굵게 강조됩니다.
  • 내비 앱으로 넘깁니다[가장 빠른 내비로 출발하기]를 누르면 선택한 앱이 열리고 목적지가 전달됩니다. 이후의 안내는 그 앱의 몫입니다.

왜 서버를 한 번 거치나

세 서비스의 API 키를 브라우저에 두면 누구나 개발자 도구로 꺼내 볼 수 있습니다. 그래서 키는 서버(Vercel 서버리스 함수)의 환경변수에만 두고, 브라우저에는 결과 JSON만 돌려줍니다. 페이지 소스 어디에도 키 문자열은 남지 않습니다. 서버 함수는 정해진 경로와 좌표 형식만 받아 각 서비스의 길찾기 엔드포인트로 넘기며, 그 밖의 요청은 거부합니다.

티맵, 카카오내비, 네이버지도는 각 회사의 상표이며, 누빠는 그 어느 회사와도 제휴·후원·보증 관계가 없는 독립 서비스입니다. 각 서비스의 데이터는 해당 회사의 이용약관에 따라 API로 제공받아 화면에 표시합니다.

운영 원칙

  • 값을 지어내지 않습니다

    한 서비스가 응답하지 않으면 그 자리에 추정값을 넣지 않고 실패 사유를 그대로 표시합니다. 없는 숫자로 비교표를 채우면 도구 전체를 믿을 수 없게 되기 때문입니다.

  • 모으지 않는 것이 기본입니다

    계정도, 서버 데이터베이스도 없습니다. 즐겨찾기는 이용자 브라우저에만 저장되고, 위치는 버튼을 누른 순간 한 번만 읽습니다. 자세한 내용은 개인정보처리방침에 있습니다.

  • 광고가 도구를 가리지 않게 합니다

    운영 비용은 페이지 광고로 충당합니다. 지도, 비교 카드, 출발 버튼 위에는 광고를 두지 않고, 안내 문서와 하단 영역에만 배치합니다.

  • 틀린 것은 고칩니다

    오류 신고와 기능 제안은 모두 읽고, 재현되는 문제는 우선 고칩니다. 알려 주실 곳은 문의하기입니다.

운영 형태

누빠는 2026년 11월에 공개된 개인 운영 서비스입니다. 별도 법인이나 대규모 조직이 아니라, 한 사람이 만들고 고치며 운영합니다. 서버는 Vercel의 서버리스 환경에서 돌아가고, 각 내비 업체가 제공하는 무료 API 한도 안에서 운영됩니다. 그래서 이용자는 무료로 쓸 수 있지만, 한도나 업체 정책이 바뀌면 기능이 일시 중단될 수 있습니다. 그때는 숨기지 않고 화면에 사유를 표시합니다.
